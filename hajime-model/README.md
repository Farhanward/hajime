# hajime-model

نموذج صغير مجاله هذا النظام، مُدرَّب على هذا النظام.

ليس نموذجاً لغوياً. لا يكتب مقالاً ولم يُقصد به ذلك. موضوعه كله Hajime: ما
يعمل، وما يعتمد على ما، وما يسع في الذاكرة الباقية، وما الذي سيفعله طلب معيّن
فعلاً.

## الأرقام

| | |
|---|---|
| زمن التدريب | 0.10 ثانية على معالج عادي |
| حجم الأوزان | 176 كيلوبايت |
| متن التدريب | 2899 جملة، مولَّدة من النظام |
| دقة التدريب | 1.000 |
| دقة على صياغات لم يرها | **0.778** (45 جملة، 11 صنفاً، التخمين 0.09) |
| اعتماديات | لا إطار، لا أوزان منزَّلة، لا مُجزِّئ |

## أربعة أجزاء

**`world.rs` — البنية.** فكرة CAD مطبَّقة على خادم: كيانات، وقيود بينها، وحلّال
يقول ما يفعله التغيير قبل أن يفعله أحد. الكيانات تُقرأ من نفس جداول `hajimectl`،
فلا يمكن أن تنحرف عنها.

**`classify.rs` — اللغة.** انحدار لوجستي متعدد فوق n-grams محرفية مُجزَّأة،
مُدرَّب هنا من الصفر. الحساب كله في الملف، ولا إطار تحته.

**`plan.rs` — القرار.** يجمع الاثنين. النية غير المؤكدة تصير **سؤالاً** لا
أمراً، ونموذج العالم يملك حق النقض، ولا شيء هنا ينفّذ.

## القسمة التي تجعله آمناً

الصياغة ضبابية فتُتعلَّم. أسماء الخدمات ليست ضبابية: تأتي من الجدول وتُطابَق
حرفياً. **لا يوجد تسلسل حروف يكتبه أحد يجعل النموذج يسمّي خدمة غير موجودة.**
تخمين خاطئ للنية يُنتج سؤالاً؛ ولا يوجد مسار يُنتج أمراً على خدمة مخترَعة.

## الاستعمال

```bash
hajime-model ask "أوقف كادي"
```

```
Stop caddy?  (confidence 0.94)
  frees about 50 MB; this is an essential service: the sites go down;
  these stop working too: cloudflared

  run it yourself if that is what you meant:
  hajimectl stop caddy
```

يخرج بالرمز 10: مفهوم، ويحتاج موافقتك. أوامر أخرى:

```bash
hajime-model explain mysql      # الاعتماديات وما يسقط معها
hajime-model check              # القيود مقابل ما يعمل الآن
hajime-model ask --json "..."   # لبرنامج آخر
hajime-model train weights.json # درّب واكتب الأوزان
hajime-model accuracy           # ما يسجّله على صياغات محجوزة
```

رموز الخروج: 0 نُفِّذ، 10 يحتاج موافقة، 1 مرفوض، 3 غير مفهوم.

خطة تحتاج موافقة **لا تُنفَّذ** تلقائياً. السؤال الذي تحمله موجَّه لإنسان،
والإجابة عليه ممن سأله تجعل خطوة التأكيد زينة.

## الحدود، مذكورة صراحةً

**لا يتعلّم ترتيب الكلمات.** «stop after starting caddy» و«start after stopping
caddy» متشابهتان عنده. لا شيء في سطح الأوامر يعتمد على هذا الفرق.

**يعرف نظاماً واحداً.** سُئل عن غيره يقول إنه لا يفهم، وهذا هو السلوك الصحيح.

**0.778 ليست 1.0.** ما يهم أكثر: متوسط الثقة في الإصابات 0.67 وفي الأخطاء 0.43،
فالعتبة تحوّل معظم الأخطاء إلى سؤال. و`stop` تسأل دائماً وتسمّي ما سيسقط معها.

## إعادة القياس

```bash
cargo run -p hajime-model --example diagnose --release   # ما يخطئ فيه وبأي ثقة
cargo run -p hajime-model --example sweep --release      # اختيار المعاملات بالقياس
```

المعاملات في `classify.rs` هي ما قاله المسح، لا ما بدا حسناً.
