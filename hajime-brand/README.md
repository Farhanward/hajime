# hajime-brand

مصدر مظهر النظام. لوحة ألوان واحدة وهوية واحدة، ومولّد يطبع منهما كل ما تحتاجه
الطبقات: المُقلِع، وطرفية النواة، وسطح المكتب، وصفحة الكونسول.

## لماذا مجلد مستقل

قبله كانت العشرون لوناً مكتوبة بخط اليد في ثلاثة مواضع: ستايل الكونسول، وستايل
GTK، وثلاثيات عشرية في `wayfire.ini`. أول تعديل على أحدها كان يجعل الأسطح تختلف
على معنى الأحمر. الآن `palette.toml` مصدر واحد، وكل ما عداه يُطبع منه.

## البنية

| المسار | ماذا فيه |
|---|---|
| `palette.toml` | اللوحة، وخريطة الستة عشر لوناً لخانات `vt(4)` |
| `brand.toml` | الاسم والمستودع والمؤلف ورابط الدعم. حقل فارغ يعني أن السطر يختفي |
| `tools/` | المولّد: `px` أساسيات البيكسل، `mascot` الماسكوت، `city` الخلفية، `scenes` الإقلاع والسبلاش، `desktop` صورة سطح المكتب، `ui` عناصر الواجهة، `emit` الكتابة |
| `out/` | المخرَجات المرفوعة. لا تُحرَّر يدوياً |
| `fonts/` | ثلاثة خطوط برخصة OFL، ومعها نصوص رخصها |
| `icons/` | أيقونات Lucide (ISC) وPhosphor (MIT) كما نُزِّلت، ومعها رخصتاهما |
| `desktop/` | مشغّلات `.desktop`، كل واحد بـ `Name` و`Name[ar]` |
| `rc.d/`, `bin/`, `login.conf.hajime` | خدمة سبلاش الإقلاع، مبدّل اللغة، وصفّا الدخول |

## التشغيل

```bash
python tools/emit.py            # يكتب out/
python tools/emit.py --check    # يفشل إن انحرف المرفوع عن المولَّد
sh check_wiring.sh              # يتحقق أن كل مسار يشير إليه شيء موجود فعلاً
sh install_theme.sh --dry-run   # على FreeBSD: يعرض الخطة بلا تغيير
sh verify_theme.sh              # على الجهاز: ماذا فيه فعلاً الآن
```

`verify_theme.sh` هو الضمان. يفرّق بين ثلاث حالات لكل شيء: **live** يعني أن
النظام الشغّال يستعمله الآن، و**written** يعني أنه في الملف وسيسري عند الإقلاع
التالي، و**missing** يعني أنه غير موجود. الفرق بين الأولين هو الفرق بين إعداد
مُنسَّق ونظام مُنسَّق: سطر في `loader.conf` يثبت أن أحداً كتبه، أما `kenv` فيقرأ
البيئة التي سلّمها المُقلِع للنواة قبل أن يوجد userland — أي أن النواة تجيب بنفسها.

المولّد يحتاج بايثون مع Pillow، وImageMagick مبنياً على raqm وlibrsvg (للنص
العربي وتصيير الأيقونات). الخادم لا يحتاج أياً منهما: الأصول مولَّدة ومرفوعة،
والمثبّت ينسخها.

## قاعدتان تفسّران أغلب الكود

**الماسكوت مكتوب بالكود، والأيقونات ليست كذلك.** الروبوت يظهر بستة مقاسات، من
مفضلة بستة عشر بكسلاً إلى ربع شاشة إقلاع؛ تكبير صورة واحدة يعطي عجينة وتصغيرها
يعطي ضجيجاً. أما أيقونات الواجهة فمن مكتبات مفتوحة: من يرسم أيقونات رسم «مجلد»
أفضل مما نرسمه هنا.

**النص ناعم الأطراف، والأشكال ليست كذلك.** كل شيء يُرسم على شبكة ربع الدقة ثم
يُكبَّر بعدد صحيح، بلا تنعيم. النص استثناء تحت مقاس العناوين: العتبة الثنائية
تقضم منحنيات الحروف الصغيرة وتحذف ضربات كاملة، فتصير التسمية موجودة وغير مقروءة.
